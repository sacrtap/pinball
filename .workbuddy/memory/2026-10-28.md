## 弹珠机预测系统 v2.0 升级（架构 + 算法深度研究）
- 用户提出三点：改用 PostgreSQL 服务端存储、增加登录与多租户隔离、算法加深（蒙特卡洛等）。
- 调研结论：
  - 多租户：共享 schema + tenant_id + PostgreSQL RLS（FORCE ROW LEVEL SECURITY + set_config 事务本地变量）为最佳实践；应用层租户绑定仓储 + RLS 双层防护；middleware 不可作唯一授权层（CVE-2025-29927）。
  - 认证：Auth.js v5 + Argon2id；JWT 携带 tenantId。
  - 算法：发力推荐本质是 contextual bandit → Thompson 采样（Beta 后验、O(log T) 后悔）；蒙特卡洛高尔顿板模拟（二项 Binomial(n,p)，中心 np）用于物理先验/What-if/失拟检验；层次贝叶斯部分池化做冷启动。

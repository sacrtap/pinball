# step1 布局压缩：推荐卡精简 + 加注键盘压缩

## Goal

发力与加注页（step1）在 390×844 视口下超出屏幕高度，用户需滑动才能看到发力选择按钮。压缩推荐卡非热力条部分的呈现方式（更精简），加注键盘压缩为 3 行紧凑布局，使 step1 一屏可见所有操作。

## Background

当前 step1 垂直堆叠（space-y-4）：
- 累计统计 ~48px + 步骤指示 ~28px + 标题 ~28px
- 推荐卡 ~220px（标题+大字档位+三档概率条+命中/中奖+12通道热力条~80px+说明文字）
- 加注面板 ~280px（总珠数大字框~90px + 12键4行面板~224px）
- 发力选择 ~80px + 上一步 ~48px
- 合计 ~732px，加 BottomNav pb-16 后 >844 可视区

两大高度元凶：12键面板(224px) + 推荐卡非热力条部分(~140px)

## Requirements

### R1 加注键盘压缩
- `ExtraBetStepper.tsx` 数字键 `min-h-14`（56px）→ `min-h-10`（40px），4行 × 40px = 160px（省 64px）
- 总珠数显示框压缩：`text-4xl` → `text-2xl`，`p-3` → `p-2`，省 ~20px
- 键盘 `gap-2` → `gap-1.5`，省 ~6px

### R2 推荐卡非热力条部分精简
- 保留：推荐档位标识 + 三档概率条 + 命中/中奖数值 + 12通道热力条
- 精简方向（由实施时定具体形态，目标省 ~60px）：
  - 推荐档大字 `text-3xl` → `text-xl`，与置信说明同行而非独立块
  - 三档概率条行间距压缩（`gap-1.5` → `gap-1`，`space-y-1` → `space-y-0.5`）
  - 卡片 padding `p-3` → `p-2`，`space-y-2` → `space-y-1.5`
  - 命中/中奖数值 `text-sm` → `text-xs`
  - 去掉冗余说明文字或缩短

### R3 不动项
- 12 通道热力条保留在推荐卡内（用户明确要求保留）
- 热力条数据计算逻辑不变
- step0/step2 渲染不变
- PowerPicker 不动（已紧凑）
- 累计统计/步骤指示/标题不动

## Acceptance Criteria
- [ ] step1 在 390×844 视口下一屏可见全部操作（推荐卡+加注+发力+上一步），无需滑动
- [ ] 推荐卡热力条仍显示，12 通道数据完整
- [ ] 加注键盘仍可正常输入 5~15 珠
- [ ] 推荐卡推荐档位、三档概率、命中/中奖数值仍可读
- [ ] typecheck/lint/vitest 全绿
